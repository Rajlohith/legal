Frequently Asked Questions
Detailed Search lets you filter cases across a date range by bench, judge, case type, and party names (petitioner or respondent). Use it when you need to find multiple cases or don't have an exact case reference.

Quick Search mirrors the court website's "Quick Search by Case No." page, it looks up a single specific case using its exact Case Type, Case Number, and Year. Use it when you already have the full case reference.
Type your query in plain English. For example: "Find writ petitions filed by Nandeesh against the State of Karnataka in 2023". The assistant interprets your request and can guide you to the right search tool, suggest what fields to fill, or answer general questions about the application.
Go to Detailed Search. Select a Bench (required), then optionally choose a judge, case type, party names, advocate names, and a date range. Click ▶ Run Search. The app auto-solves the CAPTCHA and retrieves results page by page. When complete, download an Excel file of all results using the Download Excel button.
Go to Quick Search. Select a Bench, then choose the Case Type, enter the Case Number, and select the Case Year. All three are required. Click ▶ Run Search. The CAPTCHA is solved automatically and the case details are fetched directly from the court website.
The Karnataka Judiciary website limits each query to a maximum of 90 days. If your selected date range is longer, the app automatically splits it into consecutive 90-day windows and runs them in sequence, then combines all results into a single output.
The app uses an automated CAPTCHA solver configured on the backend. You don't need to solve CAPTCHAs manually, they are handled transparently for every request. If a CAPTCHA fails, the app retries automatically before reporting an error.
In Detailed Search, use the Search multiple entities field. Enter multiple party names, one per line, or comma-separated. The app runs a separate search for each name and combines all results into a single output. Use the dropdown next to the text area to choose whether the names apply to the Petitioner or Respondent field.
After a search completes, a Download Excel button appears in the Results section. You can set a custom filename in the Save results as field before running the search. The downloaded Excel file contains all case details retrieved, including party names, case type, bench, and order information.
The application connects to a local backend server via WebSocket to stream live logs and results. If the status stays at "Connecting…" or keeps showing "Reconnecting…", ensure the backend server is running. Refer to the project README for setup and startup instructions.
